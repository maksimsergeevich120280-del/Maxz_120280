# Оперативный журнал горного диспетчера — EXE (база Step 128)

Этот проект собирается заново на основе `journal_step128_возвращено_обычное_окно_входа.html`. В `journal_step127.html` включён HTML шага 128: возвращено обычное окно входа; сохранение и JSON-механизмы не изменялись.

## Состав
- `journal_step127.html` — интерфейс журнала с исправлением окна входа (шаг 128); имя файла сохранено для совместимости с Electron-проектом.
- `main.js` — Electron main process: диалоги JSON, атомарная запись, контроль revision, обновление HTML из общей папки и резервный откат.
- `preload.js` — безопасный мост к функциям Electron.
- `package.json` — Electron 22.3.27 и electron-builder 22.14.13, установщик NSIS.
- `.github/workflows/build-windows.yml` — сборка установщика Windows через GitHub Actions.

## Сборка через GitHub
1. В репозитории `maksimsergeevich120280-del/journal-exe-step104` открой вкладку **Code**.
2. Удали/замени старые исходники проекта только после того, как скачан ZIP нового пакета и проверен его состав. Не удаляй историю репозитория.
3. Загрузи файлы и папку `.github/workflows` из этого пакета в корень репозитория; подтверди замену одноимённых файлов.
4. Сделай Commit changes в ветку `main`.
5. Открой **Actions → Build Windows EXE → Run workflow**. Дождись зелёного статуса.
6. Открой успешный запуск и скачай артефакт `Journal-Dispatcher-Windows-Installer`.

## JSON-данные
Приложение хранит путь к рабочему JSON в настройках пользователя Windows, а сами данные — в выбранном JSON-файле. Для общего доступа на нескольких компьютерах укажи один и тот же JSON-файл в сетевой папке сервера. Перед запуском на рабочих компьютерах сначала протестируй на копии JSON.

Формат поддерживаемого документа: `format: "ops-journal-shared-v1"`, `formatVersion: 2`, `payload.baimskaya_ops_journal_v1` и revision.

## Обновление HTML через общую папку
Положи в одну папку на сервере `latest.json` и HTML-файл обновления. Манифест должен включать `versionCode` (число больше 128), `version`, `date`, `title`, `description`, `changes` (массив строк), `file` (имя HTML-файла в этой же папке). В приложении выбери эту папку и нажми «Проверить обновления».

**Ограничение текущего прототипа:** updater обновляет HTML-интерфейс журнала, а не сам установленный Electron runtime. Перед массовым применением необходимо испытать обновление/откат и совместную работу с сетевым JSON на тестовой копии данных.

## Важно
- Рабочий JSON не лежит внутри каталога приложения и не заменяется при HTML-обновлении.
- Это чистая исходная сборка, а не подтверждённая тестированием готовая производственная версия. Сначала собери и проверь её на одном ПК.

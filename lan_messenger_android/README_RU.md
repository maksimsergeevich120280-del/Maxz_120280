# LAN Messenger — Android prototype 0.1.0

## Что умеет прототип
- На одном телефоне можно запустить HTTP-сервер в локальной Wi-Fi-сети.
- На втором телефоне можно указать IP первого телефона и подключиться.
- Отправка и получение текстовых сообщений.
- История хранится на телефоне-сервере (до 500 последних сообщений).
- Сборка APK через GitHub Actions.

## Важно
Это ранний прототип для доверенной локальной сети. В этой версии нет учётных записей, паролей, шифрования трафика, вложений и звонков. Не используйте его для передачи конфиденциальных данных и не открывайте порт 8080 в интернет.

## Сборка APK на GitHub
1. Загрузите содержимое папки проекта в корень репозитория (папку `.github` тоже нужно загрузить).
2. Откройте вкладку **Actions**.
3. Выберите **Build Android APK**.
4. Нажмите **Run workflow** → **Run workflow**.
5. Дождитесь зелёной отметки завершения сборки.
6. Откройте завершённый запуск и внизу страницы **Artifacts** скачайте `LAN-Messenger-debug-APK`.
7. Распакуйте скачанный ZIP — внутри будет `app-debug.apk`.

## Первый тест
1. Установите APK на два Android-телефона и подключите их к одной Wi-Fi-сети.
2. На первом телефоне откройте приложение и нажмите **Запустить сервер**.
3. Узнайте IP-адрес первого телефона из показанного статуса. Если отображается `не определён`, найдите IP в настройках Wi-Fi телефона.
4. На втором телефоне введите своё имя и IP первого телефона, затем нажмите **Подключиться**.
5. Отправьте тестовое сообщение.

Если Android спросит разрешение/покажет предупреждение при установке APK, это может быть связано с тем, что APK отлаживаемый и не опубликован в магазине.

ЖУРНАЛ EXE 127 — ПАКЕТ ДЛЯ GITHUB

Основа: доступный EXE-пакет версии 125. Версия 127 подготовлена отдельной копией проекта; интерфейс, вход через криптоключ и остальные разделы сохранены, кроме точечных исправлений сохранения JSON и обновлений.

Исправления в версии 127:
- кнопка сохранения выбирает только существующий JSON; создание нового JSON через кнопку отключено;
- после выбора/обновления данные применяются в открытом интерфейсе без перезагрузки страницы или перезапуска приложения;
- показываются автор и дата создания, автор и дата последнего сохранения;
- перед записью сравнивается SHA-256 файла; внешнее изменение вызывает предложение загрузить актуальные данные;
- после загрузки изменения записываются в тот же выбранный файл;
- сохраняется активная сессия входа; после обновления данных права интерфейса применяются повторно;
- путь к папке обновлений запоминается; проверка latest.json читает versionCode, показывает найденную версию и сравнивает её с установленной; после обновления версия учитывается повторно;
- Electron API доступен как window.electronAPI и window.api.

Сборка: GitHub Actions → Build Journal EXE 127. Артефакт: Journal-127-Setup.exe.

Важно: пакет проверяется статически и синтаксически; запуск на реальном Windows-компьютере требуется для финальной проверки.
